# История изменений

## 22.10.2026 — папка hooks

### Изменено
- Все хуки перенесены в новую папку `src/hooks/` (через `git mv`): `useMemoryGame.js`, `useTranslation.js`,

## 22.10.2026 — мобильная версия

### Добавлено
- **Мобильная версия**: игра помещается на экран телефона (проверено на ширине 360 и 380 px).
  - `<meta name="viewport">` в `index.html` — телефон больше не уменьшает страницу как десктопную;
  - поле: на телефоне сложный уровень 6×8 вместо 8×6 (`mobileColumns` в `core/levels.js`),
    меньше промежутки, размер иконок подстраивается под ширину экрана; подпись уровня показывает размер поля для экрана;
  - статус и кнопки управления компактнее и переносятся; переключатель уровня столбиком;
    рекорды компактнее; в таблице результатов на телефоне скрыты «Попытки» и «Время», столбцы тянутся по ширине;
  - крупные заголовки уменьшаются на узких экранах (`responsiveFontSizes`);
  - без задержки нажатия и увеличения по двойному тапу; увеличение карточки при наведении — только для мыши.
- Хук `core/useIsMobile.js`.

### Исправлено
- Игровой экран сжимался по содержимому, и на узком экране поле вылезало за край — теперь экран во всю ширину.

## 22.10.2026 — звёзды и открытие уровней

### Добавлено
- **Звёзды за партию** (1–3) по итоговому счёту; пороги свои у каждого уровня (`starScores` в `core/levels.js`).
  Звёзды показаны на экране победы, лучшие звёзды уровня — на его кнопке, в таблице результатов — столбец «Звёзды».
- **Открытие уровней**: сложный открывается после первой победы на среднем (`unlockedBy` в `core/levels.js`).
  Закрытый уровень неактивен, под переключателем написано, как его открыть; на экране победы —
  «🔓 Открыт новый уровень». Старые результаты (средний уровень) уже открывают сложный.
- Модуль `core/progress.js` (лучшие звёзды, открытые уровни — по сохранённым результатам),
  компонент `Stars.jsx`, функция `calculateStars` в `core/score.js`, поле `stars` в результате,
  `newUnlocks` в состоянии игры.
- Если сохранённый в настройках уровень закрыт, выбирается средний.

## 22.10.2026 — рефакторинг

Поведение игры не менялось.

### Изменено
- **Меньше бандл:** убрана библиотека `moment` (нужна была только для формата даты) —
  `bundle.js` уменьшился с 1,03 МБ до 763 КБ (−28%). Дата форматируется функцией `formatDate`.
- **Производительность:** раньше каждый тик таймера (раз в секунду) перерисовывал всё приложение
  со всеми карточками. Теперь компоненты читают из стора только нужные поля, а карточки
  (`React.memo` + стабильный обработчик) перерисовываются, только когда меняются сами.
- Старт и завершение партии — thunk'и `startNewGame()` / `finishGame()` в `store/thunks.js`
  (старт раньше был продублирован в двух компонентах, сохранение результата жило в хуке).
- Правила игры вынесены в чистые функции `core/rules.js`: `getOpenIndexes`, `isPairMatch`, `isBoardCleared`.
- Класс `Helper` заменён функциями в `core/utils.js`: `shuffle`, `formatTime`, `formatDate`.

### Переименовано (через `git mv`, история файлов сохранена)
- `components/DenseAppBar.jsx` → `AppHeader.jsx`, `Grid.jsx` → `ResultsTable.jsx`
  (не путать с `Grid` из MUI), `Try.jsx` → `Attempts.jsx`
- `core/Helper.jsx` → `utils.js`, `core/Language.js` → `languages.js`
- `store/*.jsx` → `store/*.js` — расширение .jsx оставлено только у файлов с JSX

## 22.10.2026 — уровни сложности

### Добавлено
- **Уровни сложности**: лёгкий 4×4 (8 пар), средний 6×6 (18 пар), сложный 8×6 (24 пары).
  Переключатель на стартовом экране, выбранный уровень запоминается.
- У каждого уровня своё время показа карточек в начале (1,5 / 2 / 3 сек)
  и множитель итогового счёта (×0,5 / ×1 / ×1,5).
- Рекорды и статистика отдельные для каждого уровня. Результаты, сохранённые до появления
  уровней, относятся к среднему (тогда поле было 6×6).
- На экране победы показываются уровень партии и множитель счёта.
- 6 новых иконок (лапка, звезда, сердце, нота, мяч, кофе) — всего 24. Для каждой партии
  иконки выбираются случайно, поэтому раскладки разные даже на одном уровне.

### Изменено
- Поле карточек — CSS-сетка с числом колонок по уровню (вместо сетки MUI 6 колонок).
- Бонус за точность считается от числа пар уровня, а не от фиксированных 18.
- «Заново» начинает новую партию на том же уровне.
- Сохранение настроек в `localStorage` (язык, тема, уровень) — общим списком в `store.jsx`.

### Исправлено
- Имя файла `src/core/Themes.js` → `themes.js` в git. На диске (Windows) файл уже назывался
  `themes.js` и импортировался так, но в репозитории оставалось старое имя — при клонировании
  на Linux (например, на хостинге) сборка падала бы.

### Код
- Новый модуль `src/core/levels.js` — описание уровней (`levelList`, `getLevel`, `DEFAULT_LEVEL`).
- В состоянии игры: `level` (выбранный уровень) и `roundLevel` (уровень текущей/последней партии,
  фиксируется при старте, чтобы смена уровня после победы не пересчитывала результат).
- `resetItems(levelKey)`, `calculateScore({..., level})`, `getRecords(level)`, `loadSortedResults(level)`
  принимают уровень.

## 21–22.10.2026 — новые механики, рефакторинг, чистка

### Добавлено
- Показ всех карточек в начале партии; таймер стартует после.
- Анимация переворота карточек (справа налево при открытии, обратно при закрытии).
- Подсветка пары: зелёная — угадана, красная — нет.
- Очки и серии: 100 за пару, +50 за каждую следующую подряд; бонусы за время и точность.
- Пауза: кнопка, Esc, автопауза при переключении вкладки.
- Подсказка раз за партию (все карточки на 1 сек, −500 к итогу).
- Кнопки «Заново» и «Сдаться» с подтверждением; пока окно открыто, игра на паузе.
- Рекорды (лучший счёт, время, серия) и «🏆 Новый рекорд!»; статистика отсортирована по очкам.
- README с описанием игры и кода, JSDoc-комментарии во всех модулях.

### Изменено
- Рефакторинг: логика партии вынесена в хук `useMemoryGame`, колода генерируется из списка иконок,
  стили на `sx`/`styled` вместо устаревшего `makeStyles`, тексты через `useTranslation`.
- Удалены неиспользуемые зависимости (`react-scripts`, `@mui/styles`, `react-moment` и др.),
  явно добавлены `style-loader`, `css-loader`, `@emotion/react`.
- Удалены неиспользуемые `Items.jsx` и `Statistics.jsx`.
