# История изменений

## 22.10.2026 — средний уровень 4×9 на телефоне

### Изменено
- **Средний уровень на телефоне — 4×9** (4 в ширину, 9 в высоту) вместо 6×6: карточки крупнее, поле вытянуто
  по экрану телефона. Пар столько же (18), на компьютере поле прежнее (6×6). `mobileColumns: 4` в `core/levels.js`.

## 22.10.2026 — всплывающие очки

### Добавлено
- **Всплывающие очки**: над последней открытой карточкой угаданной пары на секунду всплывает зелёная плашка
  с очками за пару — «+100», «+150 🔥×2», «+200 🔥×3»… Видно, за что даются очки и как растёт серия.
  При «уменьшить движение» плашка не поднимается, только появляется и гаснет.
  Компонент `PointsPopup.jsx`, функция `getPopup` в `useMemoryGame`, проп `popup` у `MemoryCard`.

## 22.10.2026 — переключатель вибрации

### Добавлено
- **Переключатель вибрации** в шапке (рядом с тёмной темой): телефон с волнами — включена,
  перечёркнутый — выключена. По умолчанию включена, выбор запоминается (`vibration` в настройках).
  Кнопка видна только на устройствах, где вибрация возможна (`canVibrate()` в `core/vibration.js`):
  на компьютерах и iPhone её нет. Подсказки на всех 6 языках.

## 22.10.2026 — вибрация

### Добавлено
- **Вибрация на телефоне**: угаданная пара — короткий толчок, неугаданная — двойной, победа — три.
  Работает в браузерах Android; на iPhone и компьютерах её нет (браузер не поддерживает) — игра идёт как раньше.
  Модуль `core/vibration.js` (`vibrate`, узоры `VIBRATION`), вызовы — в `hooks/useMemoryGame.js`.

## 22.10.2026 — плавный переход

## 22.10.2026 — конфетти

## 22.10.2026 — лёгкий бандл

### Изменено
- **Бандл почти вдвое меньше: 779 → 429 КБ.**
  - Таблица результатов переписана на обычных компонентах MUI (`Table`, `TableSortLabel`, `TablePagination`)
    вместо `@mui/x-data-grid` (бета-версия 2021 года, самая тяжёлая зависимость). Возможности те же:
    сортировка кликом по заголовку (по умолчанию — по очкам), 5 результатов на странице, заглушка для пустого уровня,
    на телефоне скрыты «Попытки» и «Время». Подпись страниц без слов: «1–5 / 8».
  - Убран `babel-polyfill` (устарел): MUI v5 и так работает только в современных браузерах, где всё нужное есть.
- `getResultSeconds` в `core/storage.js` экспортируется (сортировка таблицы по времени).
- Из `package.json` и `package-lock.json` удалены `@mui/x-data-grid` и `babel-polyfill` (и пакеты, нужные только им).

## 22.10.2026 — тёмная тема и CLAUDE.md

### Исправлено
- Причина, по которой первая тёмная тема ломала приложение: фон `whitesmoke` в теме MUI. MUI принимает
  только коды цветов и падал при запуске (ошибка MUI #9). Теперь фон — `#f5f5f5` (тот же цвет), задаётся темой, а не `main.scss`.

### Добавлено
- **Тёмная тема**: кнопка в шапке (луна / солнце), выбор запоминается (`darkMode` в настройках).
  Работает со всеми цветами оформления; в тёмном режиме основной цвет осветляется для читаемости,
  шапка остаётся цветной. Тема создаётся функцией `createAppTheme(цвет, тёмный режим)` в `core/themes.js`.
- `CLAUDE.md` — правила работы с проектом для Claude Code (VS Code, терминал): документация вместе с кодом,
  коммиты только по команде, хуки в `src/hooks/`, переименования через `git mv` и др.

## 22.10.2026 — рефакторинг

Поведение игры не менялось.

### Изменено
- **Меньше бандл:** убрана библиотека `moment` (нужна была только для формата даты) —
  `bundle.js` уменьшился с 1,03 МБ до 763 КБ (−28%). Дата форматируется функцией `formatDate`.
- **Производительность:** раньше каждый тик таймера (раз в секунду) перерисовывал всё приложение
  со всеми карточками. Теперь компоненты читают из стора только нужные поля, а карточки
  (`React.memo` + стабильный обработчик) перерисовываются, только когда меняются сами.
- Старт и завершение партии — thunk'и `startNewGame()` / `finishGame()` в `store/thunks.js`
  (старт раньше был продублирован в двух компонентах, сохранение результата жило в хуке).
- Правила игры вынесены в чистые функции `core/rules.js`: `getOpenIndexes`, `isPairMatch`, `isBoardCleared`.
- Класс `Helper` заменён функциями в `core/utils.js`: `shuffle`, `formatTime`, `formatDate`.

### Переименовано (через `git mv`, история файлов сохранена)
- `components/DenseAppBar.jsx` → `AppHeader.jsx`, `Grid.jsx` → `ResultsTable.jsx`
  (не путать с `Grid` из MUI), `Try.jsx` → `Attempts.jsx`

- `store/*.jsx` → `store/*.js` — расширение .jsx оставлено только у файлов с JSX

## 22.10.2026 — уровни сложности

### Добавлено
- **Уровни сложности**: лёгкий 4×4 (8 пар), средний 6×6 (18 пар), сложный 8×6 (24 пары).
  Переключатель на стартовом экране, выбранный уровень запоминается.
- У каждого уровня своё время показа карточек в начале (1,5 / 2 / 3 сек)
  и множитель итогового счёта (×0,5 / ×1 / ×1,5).
- Рекорды и статистика отдельные для каждого уровня. Результаты, сохранённые до появления
  уровней, относятся к среднему (тогда поле было 6×6).
- На экране победы показываются уровень партии и множитель счёта.
- 6 новых иконок (лапка, звезда, сердце, нота, мяч, кофе) — всего 24. Для каждой партии
  иконки выбираются случайно, поэтому раскладки разные даже на одном уровне.

### Изменено
- Поле карточек — CSS-сетка с числом колонок по уровню (вместо сетки MUI 6 колонок).
- Бонус за точность считается от числа пар уровня, а не от фиксированных 18.
- «Заново» начинает новую партию на том же уровне.
- Сохранение настроек в `localStorage` (язык, тема, уровень) — общим списком в `store.jsx`.

### Исправлено
- Имя файла `src/core/Themes.js` → `themes.js` в git. На диске (Windows) файл уже назывался
  `themes.js` и импортировался так, но в репозитории оставалось старое имя — при клонировании
  на Linux (например, на хостинге) сборка падала бы.

### Код
- Новый модуль `src/core/levels.js` — описание уровней (`levelList`, `getLevel`, `DEFAULT_LEVEL`).
- В состоянии игры: `level` (выбранный уровень) и `roundLevel` (уровень текущей/последней партии,
  фиксируется при старте, чтобы смена уровня после победы не пересчитывала результат).
- `resetItems(levelKey)`, `calculateScore({..., level})`, `getRecords(level)`, `loadSortedResults(level)`
  принимают уровень.
